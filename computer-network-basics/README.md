# 计算机网络入门

- 类型：编程基础
- 难度：中级

## 运行

```bash
python run_all.py
```

## 课程大纲

1. 第1课 分层模型：一次网页请求经过了什么
2. 第2课 IP、端口与 DNS：名字怎么变成地址
3. 第3课 TCP 与 UDP：可靠、有序、连接到底意味着什么
4. 第4课 Socket 编程：用 Python 发一个 TCP 请求
5. 第5课 HTTP 报文：请求行、头部、状态码、正文
6. 第6课 HTTPS 与证书：加密、身份与中间人
7. 第7课 延迟、带宽、吞吐：为什么“网速慢”有很多种
8. 第8课 项目：本地 HTTP 客户端与服务器排错
