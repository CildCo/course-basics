# 云杉笔记产品说明

## 产品定位

云杉笔记是一款面向中小团队的本地知识库与文档检索工具。它把散落在网盘、聊天记录和个人电脑里的资料集中到一个工作区，支持导入、打标签、全文检索和引用定位。产品重点在“找得到”和“找得准”，不追求复杂的排版功能。

## 核心能力

- 文档导入：支持 Markdown、TXT、PDF 和 DOCX，导入后统一转成纯文本并建立索引。
- 全文检索：同时提供关键词检索和语义近邻检索，结果可以按文档、标签和时间筛选。
- 引用定位：每条检索结果保留文档 ID、一级标题、二级标题和段落编号，方便回到原文核对。
- 协同编辑：团队成员可以在同一工作区编辑文档，系统保留历史版本和修改记录。
- 开放接口：企业版可以调用文档查询接口，把检索结果接入自己的业务系统。

## 版本与适用团队

云杉笔记分为免费版、团队版和企业版。免费版适合个人整理资料，团队版适合十人左右的内容小组，企业版面向有私有化部署和审计要求的组织。三个版本共用同一套文档格式，升级后不需要重新导入。

## 工作方式

云杉笔记默认把文档和索引保存在本地数据目录，只有开启同步后才会把变更上传到服务器。索引由标题、段落和正文组成，检索时先召回候选片段，再由使用方决定如何展示或交给生成模型。产品本身不内置大模型，也不会上传用户文档去训练模型。

## 边界说明

检索层负责找到相关片段并给出出处，生成层负责把片段组织成通顺回答，引用层负责把回答和原文位置对应起来。三者可以分开替换。云杉笔记只保证检索和引用字段完整，回答质量取决于接入的生成层。
