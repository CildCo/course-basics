# 使用手册

## 工作区

一个工作区对应一个知识库。工作区之间数据隔离，成员、标签和索引互不影响。创建时可以选空白工作区，也可以从模板导入目录结构。工作区名称建议使用团队或项目名，方便成员识别。

## 导入文档

点击左上角“导入”，可以选择文件或整个文件夹。支持 Markdown、TXT、PDF、DOCX。Markdown 的标题层级最完整，推荐作为长期资料格式。导入时系统会读取一级标题作为文档标题，按二级标题切分章节，再按段落和长度切成检索片段。重复导入同一文件会更新原文档，不会产生副本。

## 检索与筛选

搜索框支持关键词和自然语言问题。结果默认按相关度排序，可以切换为按时间排序。左侧筛选器可以限定文档、标签、更新时间和文件类型。搜索“引用”按钮会把当前片段的位置复制到剪贴板，格式为文档 ID 加章节名。

## 协同编辑

多人协作编辑同一篇文档时，系统按段落加锁，避免整篇文档互相覆盖。成员看到的光标位置和选中的段落会实时显示。若两人同时修改同一段落，后保存的一方会收到冲突提示，可以选择保留自己的版本、保留对方版本或手动合并。历史版本默认保留 90 天。

## 标签与收藏

标签用于跨文档归类，一个文档可以有多个标签。收藏夹适合放高频资料。标签和收藏都不会改变文档正文，删除标签也不会删除文档。

## 导出与备份

可以把整个工作区导出为 Markdown 目录，也可以只导出选中的文档。导出包包含正文和元数据，不包含索引文件。备份文件可以在“设置 → 备份与恢复”中创建和恢复，恢复前建议先导出当前数据。
