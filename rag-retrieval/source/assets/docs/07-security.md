# 安全与隐私

## 数据传输

客户端与服务器之间使用 TLS 1.3 加密传输。开启同步后，文档内容、标签和索引更新都通过加密通道发送。企业版可以配置自己的证书，支持内网 CA。

## 数据存储加密

服务端静态数据使用 AES-256 加密存储，密钥由密钥管理服务托管并定期轮换。本地数据目录可以选择开启磁盘加密，开启后需要输入密码才能打开工作区。备份文件同样加密，恢复时需要对应密钥。

## 权限模型

工作区角色分为所有者、管理员、编辑者和只读成员。所有者可以删除工作区，管理员可以管理成员和套餐，编辑者可以新增和修改文档，只读成员只能查看和导出。文档还可以单独设置访问权限，未授权的成员不会在检索结果中看到该文档。

## 单点登录与审计

企业版支持 SAML 2.0 单点登录，可以对接常见身份提供商。管理员可以查看登录、导出、权限变更和删除操作的审计日志，日志默认保留 180 天。团队版不包含单点登录。

## 备份与恢复

服务端每天自动备份一次，保留 30 天。管理员可以在后台手动创建备份，也可以下载备份文件。恢复操作会覆盖当前数据，执行前需要二次确认。

## 合规

云杉笔记遵循最小权限原则，不读取与业务无关的文件。产品不会使用客户文档训练模型。需要签署数据处理协议时，可以联系客户成功经理获取模板。
