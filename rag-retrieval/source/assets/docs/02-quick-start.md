# 快速开始

## 系统要求

桌面端支持的操作系统包括 Windows 10、Windows 11、macOS 12 及以上版本，以及 Ubuntu 20.04 及以上版本。建议内存 4 GB 以上，预留 500 MB 磁盘空间。浏览器端支持最新版 Chrome、Edge 和 Safari，不支持 IE。

## 安装步骤

1. 从官网下载对应系统的安装包，双击运行。
2. Windows 用户按提示完成安装，macOS 用户把应用拖入“应用程序”目录。
3. 首次启动时选择工作区位置，可以新建，也可以打开已有目录。
4. 登录账号，或者选择“仅本地使用”跳过登录。
5. 在设置页确认索引语言为“中文”，然后点击“建立索引”。

## 数据目录

默认数据目录在 Windows 上是 `%APPDATA%\YunshanNote`，在 macOS 上是 `~/Library/Application Support/YunshanNote`，在 Linux 上是 `~/.local/share/yunshan-note`。可以在设置中修改，但修改后需要重启应用。迁移电脑时，复制整个数据目录即可保留文档、标签和索引。

## 首次配置

首次进入工作区，建议先设置默认导入目录、索引更新频率和备份策略。索引更新频率可以选择手动、启动时或每 30 分钟。备份策略默认每天一次，保留最近 7 份。

## 验证安装

打开示例文档，在搜索框输入“安装”，如果能看到示例文档的段落结果，说明导入、切分和索引都正常。若结果为空，先到“设置 → 索引状态”查看索引是否完成。
