# 开放接口指南

## 鉴权

调用开放接口前，先使用工作区 ID 和 API Key 换取访问令牌。请求头格式为 `Authorization: Bearer <token>`。令牌有效期 2 小时，过期后需要重新获取。API Key 只能在服务端保存，不要写进前端代码或公开仓库。

## 文档查询

使用 `GET /api/v1/documents/search` 查询文档片段。主要参数：

- `q`：查询文本，必填。
- `top_k`：返回片段数，默认 5，最大 20。
- `doc_id`：限定文档。
- `tag`：限定标签。

响应包含 `results` 数组，每项有 `chunk_id`、`doc_id`、`title`、`heading`、`text`、`score` 六个字段。`score` 越高表示越相关，不同检索模式的分数不可直接比较。

## 引用字段

`chunk_id` 在一次索引周期内稳定，重建索引后可能变化。需要长期引用时，请同时保存 `doc_id`、`heading` 和段落文本摘要。接口返回的 `text` 是切分后的片段，不是整篇文档。

## 错误码

- 401：令牌缺失或过期。
- 403：没有该工作区或文档的访问权限。
- 404：文档或片段不存在。
- 429：请求过于频繁。
- 500：服务端内部错误，可以稍后重试。

## 限流

默认每个 API Key 每分钟 120 次请求，瞬时并发不超过 20。超过限制返回 429，并在响应头中给出 `Retry-After`。企业版可以申请提高配额。

## 版本兼容

接口版本写在路径中，当前为 v1。新增字段保持向后兼容，删除字段会提前 90 天通知。升级客户端前，建议先在测试工作区验证。
