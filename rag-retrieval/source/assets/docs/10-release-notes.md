# 版本更新

## 2.6

- 混合检索支持配置词法权重和向量权重。
- 引用结果可以定位到段落，不再只显示文档标题。
- 修复重建索引时偶发的进度卡住问题。
- 搜索接口增加 `Retry-After` 响应头。

升级注意：2.6 首次启动会自动重建一次索引，文档较多时需要预留时间。API v1 保持兼容，不需要修改客户端。

## 2.5

- 支持按 Markdown 标题层级切分文档。
- 新增检索评估面板，可以查看命中率和平均延迟。
- 团队版历史版本从 30 天延长到 90 天。
- 修复 PDF 导入时页码错位。

2.5 的索引格式与 2.4 兼容，可以不重建，但重建后标题召回更稳定。

## 2.4

- 导入速度提升约 40%。
- 支持批量打标签。
- 新增只读成员角色。
- 修复 macOS 上偶发的白屏问题。

## 已知问题

PDF 中的复杂表格暂时无法保留行列结构，建议同时保留原始文件。Windows 7 不在支持范围内。超长段落会被切成多个片段，引用时可能跨片段。

## 升级建议

升级前备份数据目录。跨大版本升级后，先在测试工作区验证导入、检索和导出。遇到索引异常时，优先尝试重建索引，并保留日志。
