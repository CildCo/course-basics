# Python 标准库实战

- 类型：编程基础
- 难度：中级

## 运行

```bash
python run_all.py
```

## 课程大纲

1. 第1课 容器增强：Counter、defaultdict、deque、namedtuple
2. 第2课 迭代工具：itertools
3. 第3课 函数工具：functools
4. 第4课 日期与时间：datetime、time
5. 第5课 路径与文件：pathlib、os
6. 第6课 数据格式：json、csv、pickle
7. 第7课 文本与正则：re、textwrap
8. 第8课 统计与随机：statistics、random
9. 第9课 子进程与参数：subprocess、sys
10. 第10课 小工具：argparse、logging、tempfile
