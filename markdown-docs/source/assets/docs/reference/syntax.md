# 语法速查

## 标题

一级标题只出现一次，后面按二级、三级往下排。不要从一级直接跳到三级。

## 列表

- 无序列表用短横线。
- 列表项之间不要空行，除非确实要分段。
- 嵌套列表缩进两个空格。

1. 有序列表适合步骤。
2. 每一步只写一个动作。
3. 需要强调时用 **加粗**，不要整段加粗。

## 代码块

行内代码用反引号，例如 `data_path()`。多行代码要标语言：

```python
from pathlib import Path
print(Path("docs/README.md").suffix)
```

```bash
python build_site.py
```

## 表格

| 写法 | 效果 | 注意 |
| --- | --- | --- |
| `**粗体**` | **粗体** | 不要滥用 |
| `` `代码` `` | `代码` | 适合函数名 |
| `[文字](链接)` | 链接 | 链接要能打开 |

## 链接与图片

站内链接用相对路径：

- 同一目录：`[常见问题](../faq.md)`
- 下一级目录：`[安装步骤](../guide/install.md#安装步骤)`
- 回到首页：`[首页](../README.md)`

图片和链接一样，路径相对当前文档。

### 锚点规则

锚点由标题生成：转小写、去掉标点、空格换成短横线，中文原样保留。

例如标题「front matter 与元数据」的锚点是 `#front-matter-与元数据`。

手写目录时，锚点必须和渲染器生成的完全一致，否则点击没有反应。

## 最后检查

- 每个链接都能打开。
- 每个代码块都有语言标记。
- 每张表都有表头。
