# 写作流程

## 写作前先定元数据

front matter 决定页面标题、导航顺序和摘要。先写元数据，再写正文，能避免返工。

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| title | 是 | 页面标题 |
| nav | 是 | 导航显示的文字 |
| order | 是 | 排序，数字越小越靠前 |
| summary | 是 | 一句话摘要 |

## 一次完整的修改流程

1. 建一个短分支，只改一篇文档。
2. 补全 front matter，检查 title、nav、order、summary。
3. 正文先写结论，再写步骤和例子。
4. 本地生成站点，点开导航和站内链接。
5. 确认无误后提交，把生成目录排除在版本库之外。

### 本地预览

```bash
python build_site.py
start output/site/index.html
```

Windows 用 `start`，macOS 用 `open`，Linux 用 `xdg-open`。

### 提交前检查

- 相对链接是否能打开。
- 标题层级是否从一级开始，逐级往下。
- 代码块是否标了语言。
- 表格是否有表头。

## 常见返工原因

- 元数据缺字段，站点生成时排序混乱。
- 链接用了绝对路径，换目录后全部失效。
- 标题里带标点，锚点和手写目录对不上。

回到 [语法速查](../reference/syntax.md#锚点规则) 看锚点是怎么生成的。
