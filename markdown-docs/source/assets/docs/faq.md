# 常见问题

## 为什么目录链接点不开

先看链接是相对路径还是绝对路径。站内链接应该相对当前文档，例如 `../guide/install.md`。

再检查锚点：标题改了，锚点也会变，手写目录要同步更新。

最后确认文件名大小写。Windows 不区分大小写，部署到 Linux 后会区分。

## front matter 为什么解析失败

常见原因是分隔线没写完整、冒号后面缺空格、列表缩进不一致。

```yaml
---
title: 常见问题
nav: 常见问题
order: 5
tags:
  - 文档
---
```

解析前先确认文件开头就是 `---`，中间不要插空行。

## 生成站点后样式丢失

样式表要用相对路径引用。页面在 `guide/` 下时，路径要写成 `../assets/style.css`。

不要把 CSS 放在外部地址，也不要依赖网络字体。

## 中文锚点会不会失效

不会。只要渲染器和检查脚本使用同一套锚点规则，中文标题也能正常跳转。

课程里的 `slugify()` 会保留中文，只去掉标点和多余空格。

回到 [语法速查](reference/syntax.md#锚点规则) 再核对一遍。
