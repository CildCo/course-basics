# 本地知识库使用说明

这个知识库用于整理日常开发笔记，支持按关键词搜索、按分类过滤和按更新时间排序。

## 常用操作

- 新增笔记：先写普通表，再由触发器同步到全文索引。
- 搜索笔记：使用 FTS5 的 MATCH，至少输入三个字符。
- 查看标签：用 json_each 展开 tags 字段。
- 备份数据库：使用 backup API，备份后执行完整性检查。

## 设计约定

标题和正文分开存储，标题用于快速浏览，正文用于全文检索。分类和更新时间放在复合索引里，方便列表页按分类倒序展示。

## 索引优化记录

列表页最常用的查询是某个分类下最近更新的笔记，对应复合索引 (category, updated_at)。搜索页先用 MATCH 缩小范围，再按分类过滤。每次调整索引后都要用查询计划和实际耗时复测。
