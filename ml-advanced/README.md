# 机器学习进阶：集成、调参与解释

- 类型：编程基础
- 难度：高级

## 运行

```bash
python run_all.py
```

## 课程大纲

1. 第1课 建立可信基线：Dummy、简单模型与业务指标
2. 第2课 决策树与随机森林：偏差、方差与袋外误差
3. 第3课 梯度提升与 LightGBM：残差学习与早停
4. 第4课 特征工程与类别编码：目标泄漏的边界
5. 第5课 不平衡数据：重采样、class_weight 与阈值
6. 第6课 概率校准：predict_proba 为什么不可信
7. 第7课 模型解释：特征重要性、置换重要性与部分依赖
8. 第8课 集成策略：投票、堆叠与融合的收益边界
9. 第9课 超参数搜索与实验记录：从 GridSearch 到随机搜索
10. 第10课 项目：端到端建模、解释与报告
