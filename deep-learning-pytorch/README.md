# 深度学习与 PyTorch 入门

- 类型：编程基础
- 难度：高级

## 运行

```bash
python run_all.py
```

## 课程大纲

1. 第1课 张量、形状与设备：CPU 上也能学深度学习
2. 第2课 自动求导：计算图与 backward
3. 第3课 线性回归从零实现：损失、梯度、更新
4. 第4课 nn.Module 与优化器：把训练组织起来
5. 第5课 训练循环与验证：epoch、batch、早停
6. 第6课 逻辑回归与交叉熵：从分数到概率
7. 第7课 过拟合与正则：Dropout、权重衰减、数据增强
8. 第8课 CNN 基础：卷积、池化与感受野
9. 第9课 保存、加载与推理：state_dict 与模型版本
10. 第10课 项目：手写数字分类小模型
